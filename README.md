# S2K-VN Sale Page

Responsive Vietnamese landing page with animated server latency indicators and Android/iOS download calls to action.

## Preview locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

## Customize links

Replace the `href="#"` values on the Android and iOS buttons in `index.html` with the real download URLs. Replace the footer support links in the same way.
